# TASK-20260523-015 能力快照与刷新语义重构

状态：Backlog  
优先级：Medium  
上游来源：[REP-20260523](../../docs/reports/REP-20260523-credential-provider-domain-model.md)

## 目标

将能力快照与刷新动作拆成入口级、凭证级和账号分组级聚合，避免厂商聚合能力、协议入口能力和具体 key 能力互相污染。

## 范围

- 梳理刷新厂商预设、刷新站点能力、刷新模型、真实 smoke 的职责边界。
- 增加能力来源与刷新证据展示。
- 设计入口级和凭证级能力聚合策略。

## 非目标

- 不在本任务中实现 billable live smoke。
- 不删除现有 snapshot 表。

## 验收标准

- 能力矩阵能区分 gateway 已实现、站点声明、凭证验证、最近运行错误。
- MiMo 这类多入口厂商不会再出现同一能力在不同页面显示不一致。
