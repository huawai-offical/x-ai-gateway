# TASK-20260521-012-03 账号分组与治理表格操作收敛

状态：Done  
优先级：Critical  
上游来源：[TASK-20260521-012](./TASK-20260521-012-console-health-codex-model-tls-workbench-ux.md)

## 任务类型

子任务

## 背景

账号分组与治理策略表格仍有按钮过多、行高被拉大或空白区域过多的问题，需要对齐已录入凭证表格的详情弹窗模式。

## 目标

- 账号分组表格主行保持扁平，复杂操作进入详情弹窗。
- 治理表格操作列收敛，避免按钮竖排撑高。
- 保留原有启停、编辑、删除、触发等必要操作。

## 非目标

- 不重做全站表格系统。
- 不删除治理策略本身能力。

## 输入

- `web/src/features/accounts/`
- `web/src/features/governance/`

## 输出

表格操作区重排、详情弹窗或横向紧凑操作、测试更新。

## 影响范围

账号分组页、治理策略页。

## 依赖

现有 UI 组件。

## 风险

操作入口移动后需要确保用户仍能顺利找到关键动作。

## 验收标准

- [x] 账号分组表格行高稳定。
- [x] 治理表格行高稳定。
- [x] 主行不出现竖排按钮导致的大块空白。

## 测试边界

- 账号分组与治理页面相关 vitest。
- 浏览器手工检查。

## 当前状态

已完成。账号分组主表收敛到详情入口，治理策略操作改为紧凑图标按钮并更新回归测试。
