# TASK-20260525-002 文本选中态对比度修正

状态：In Progress  
优先级：High  
类型：子任务  
上游来源：用户反馈“框选字体的底色和字体颜色相近导致看不清”

## 背景

当前全局 `::selection` 只设置了浅色背景，没有显式设置选中文字颜色。在默认深色主题下，文本选中后容易出现浅蓝背景叠白色文字的低对比度问题。

## 目标

- 提高全站文本选中态的背景和文字对比度。
- 深色和浅色主题都保持可读。
- 只修改全局 CSS，不调整页面布局或组件结构。

## 非目标

- 不重做主题色板。
- 不修改按钮、输入框、表格或卡片布局。
- 不引入新的设计 token 体系。

## 影响范围

- `web/src/index.css`

## 验收标准

- `::selection` 同时设置背景色和文字色。
- 深色主题下选中文本不再出现浅底浅字。
- `cd web; bun run typecheck` 通过。

## 测试边界

- CSS 变更以浏览器视觉检查和 typecheck 为主。
- 不新增组件单测。

- 2026-05-25：任务创建，进入实现。
