# REQ-20260523-012 控制台 Apple-level UI/UX 精修

## 背景

用户在账号分组详情页指出 App Shell 左侧导航与右侧内容区的顶部对齐不够精细：侧栏滚动条、品牌区底线、右侧标题栏与内容滚动区域之间出现突兀断层。该问题属于全局控制台体验问题，不应只在单页局部修补。

现有控制台已经完成多轮功能收敛，但在视觉精细度上仍存在以下风险：

- App Shell 滚动条样式过重，侧栏滚动条在导航与内容分隔处形成明显竖条。
- 侧栏品牌区高度与右侧标题栏依赖自然内容高度，缺少统一节奏约束。
- 部分高频页面仍有多层边框、圆角和卡片嵌套，弱化了信息层级。
- 深色主题下边界线、背景透色和操作按钮的质感需要更接近系统级后台工具。

## 目标

- 修正截图中的侧栏与内容区对齐问题，让品牌区、标题栏、导航滚动区和内容滚动区形成统一顶部节奏。
- 将 App Shell 滚动条改为更轻、更接近系统原生的 hover 可见样式，避免常驻粗滚动条抢视觉焦点。
- 优化账号分组详情页及相关高频页面的 UI/UX 精细度，优先关注间距、分割线、按钮状态、卡片边界和响应式稳定性。
- 抽查厂商目录、上游凭证、账号分组列表等高频页面，记录仍需后续拆分的 UI/UX 问题。

## 非目标

- 不改账号分组、厂商、凭证、分发 Key 等业务逻辑。
- 不引入新的设计系统、动效框架或第三方 UI 依赖。
- 不做大规模信息架构重排；本次只处理可局部落地且可视觉验证的精修项。
- 不恢复已下线页面或旧控制台入口。

## 方案

- 以 App Shell 为第一优先级，将右侧 header 实测高度同步给侧栏品牌区，避免顶部节奏漂移。
- 新增轻量滚动条工具类，仅在 shell 主要滚动面应用；保留全局滚动条变量以兼容其他长列表。
- 对侧栏、顶部 header、命令搜索和用户菜单按钮做低对比、低噪声处理，减少硬边框和突兀阴影。
- 对账号分组详情页进行视觉抽查，优先处理第一屏与高频表格容器的层级问题。

## 影响范围

- `web/src/components/app/app-shell.tsx`
- `web/src/index.css`
- 账号分组详情页、厂商目录、上游凭证和账号分组列表的视觉抽查范围
- 本地文档与任务索引

## 风险

- 全局 shell 修改会影响所有控制台页面，需要通过桌面宽度和移动宽度分别检查。
- 滚动条变轻后，长列表页面仍需保留可发现性，不能完全隐藏滚动能力。
- 侧栏折叠态和移动抽屉共享 `SidebarContent`，高度和间距调整需要避免移动端错位。

## 验收标准

- 账号分组详情页第一屏中，侧栏品牌区底线与右侧标题栏底线对齐，截图标注位置不再出现突兀竖向滚动条。
- 侧栏、主内容区滚动条在默认态低干扰，hover 或滚动时仍可感知。
- 账号分组详情、厂商目录、上游凭证、账号分组列表在桌面宽度下无明显错位、重叠、过重嵌套框。
- 移动宽度下顶部操作、侧栏抽屉和主内容不出现文字溢出或遮挡。
- `bun run typecheck` 通过；如改动触及测试覆盖页面，运行对应前端测试。
